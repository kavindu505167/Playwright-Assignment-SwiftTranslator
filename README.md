# Playwright-Assignment-SwiftTranslator

This project contains automated test suites for the Swift Translator web application.

## Test Summary
- **Positive Tests:** 24 scenarios (All Passed)
- **UI Tests:** 2 scenarios for Reset functionality (All Passed)
- **Negative Tests:** 10 scenarios for validation (All Failed as expected)

## How to Run
1. Install dependencies: `npm install`
2. Run tests: `npx playwright test`
3. View report: `npx playwright show-report`
